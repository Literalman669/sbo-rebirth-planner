# SBO:Rebirth Optimizer V2 Phase 1 Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Establish a clean `optimizer-v2/` workspace on SpacetimeDB 2.8.3 with a React test shell, a minimal public dataset-release module, generated bindings, local integration tests, and CI.

**Architecture:** Keep the new application isolated from the legacy planner under `optimizer-v2/`. A Vite React client consumes generated bindings from a TypeScript SpacetimeDB module; Phase 1 proves the complete local connection and subscription path without implementing planner behavior.

**Tech Stack:** Node.js 22.22.2, npm 10.9.7, React 19.2.8, TypeScript 7.0.2, Vite 8.2.2, Vitest 4.1.11, Playwright 1.62.1, SpacetimeDB CLI/SDK 2.8.3

**Spec:** `docs/superpowers/specs/2026-08-29-sbo-rebirth-optimizer-v2-design.md`

## Global Constraints

- The CLI, server package, client SDK, and generated bindings must all report SpacetimeDB 2.8.3.
- New work lives under `optimizer-v2/`; do not refactor or delete the legacy planner during this phase.
- Generated files under `optimizer-v2/client/src/module_bindings/` are never edited manually.
- Guest use and public dataset subscriptions must not require SpacetimeAuth.
- The optimizer remains client-side and independent of SpacetimeDB; Phase 1 does not implement optimizer logic.
- Use the official current APIs documented at `https://spacetimedb.com/docs/clients/typescript/` and `https://spacetimedb.com/docs/quickstarts/react`.
- Use test-driven development for behavior, run `git diff --check` before every commit, and keep commits scoped to one task.

```ts
// optimizer-v2/client/src/infrastructure/spacetime/releaseSelection.ts
export type DatasetRelease = {
  version: string;
  formulaSetVersion: 'sbor-stats-v1';
  sourceSummary: string;
  publishedAtMicros: bigint;
  lastReviewedAt: string;
};

type LiveDatasetRelease = DatasetRelease & { isCurrent: boolean };

export function selectCurrentRelease(
  live: readonly LiveDatasetRelease[],
  fallback: DatasetRelease,
): { release: DatasetRelease; source: 'live' | 'fallback' } {
  const current = live.filter((release) => release.isCurrent);
  if (current.length > 1) throw new Error('ambiguous current dataset release');
  if (current.length === 1) return { release: current[0], source: 'live' };
  return { release: fallback, source: 'fallback' };
}
```

```tsx
// optimizer-v2/client/src/infrastructure/spacetime/PublicDataProvider.tsx
import { createContext, useContext, useMemo, type PropsWithChildren } from 'react';
import { SpacetimeDBProvider, useTable } from 'spacetimedb/react';
import { tables } from '../../module_bindings';
import { createPublicConnectionBuilder } from './connection';
import { selectCurrentRelease, type DatasetRelease } from './releaseSelection';

const fallbackRelease: DatasetRelease = {
  version: 'bootstrap-0',
  formulaSetVersion: 'sbor-stats-v1',
  sourceSummary: 'Bundled fallback',
  publishedAtMicros: 0n,
  lastReviewedAt: '2026-08-29',
};

const PublicReleaseContext = createContext<ReturnType<typeof selectCurrentRelease> & { isReady: boolean } | null>(null);

function PublicReleaseSubscription({ children }: PropsWithChildren) {
  const [rows, isReady] = useTable(tables.datasetRelease);
  const value = useMemo(
    () =>
      ({
        ...selectCurrentRelease(
          rows.map((row) => ({
            version: row.version,
            formulaSetVersion: row.formulaSetVersion as 'sbor-stats-v1',
            sourceSummary: row.sourceSummary,
            publishedAtMicros: row.publishedAt.microsSinceUnixEpoch,
            lastReviewedAt: row.lastReviewedAt,
            isCurrent: row.isCurrent,
          })),
          fallbackRelease,
        ),
        isReady,
      }),
    [rows, isReady],
  );
  return <PublicReleaseContext.Provider value={value}>{children}</PublicReleaseContext.Provider>;
}

export function PublicDataProvider({ children }: PropsWithChildren) {
  const builder = useMemo(() => createPublicConnectionBuilder(), []);
  return (
    <SpacetimeDBProvider connectionBuilder={builder}>
      <PublicReleaseSubscription>{children}</PublicReleaseSubscription>
    </SpacetimeDBProvider>
  );
}

export function usePublicRelease() {
  const value = useContext(PublicReleaseContext);
  if (!value) throw new Error('usePublicRelease must be used inside PublicDataProvider');
  return value;
}
```
